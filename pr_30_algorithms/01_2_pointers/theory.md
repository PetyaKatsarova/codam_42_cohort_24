Two Pointers Algorithm uses two pointers to traverse data structures efficiently, reducing time complexity from O(n²) to O(n).

Main Patterns:
Opposite Direction (left & right) - For palindromes, two sum, container problems
Same Direction (fast & slow) - For removing duplicates, partitioning
Sliding Window - For substring/subarray problems
Partition - For sorting/organizing elements
Complexity Analysis:
Time: O(n) - Each element visited at most once or twice

vs Brute Force O(n²) with nested loops
Space: O(1) - Only pointer variables stored

* Examples
Two Sum, Reverse String, Valid Palindrome
Remove Duplicates, Move Zeroes
Longest Substring Without Repeating
Container With Most Water, Sort Colors
And more with full implementations
