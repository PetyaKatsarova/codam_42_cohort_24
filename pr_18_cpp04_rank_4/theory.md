1. VALUE SEMANTICS (no & or )

Creates copies of objects
Object slicing occurs when copying derived objects to base type
Each object has its own memory
Automatic cleanup when going out of scope

2. REFERENCES (&)

Alias to an existing object (same object, different name)
No copying - references the original
Cannot be reassigned after initialization
Cannot be null
Enables polymorphism with inheritance

3. POINTERS (*)

Stores memory address of an object
No copying - points to the original
Can be reassigned to point to different objects
Can be null
Enables polymorphism with inheritance
Required for dynamic allocation
