HOW TO TEST practice.c
=======================

NOTE: client IDs never repeat. If client 0 disconnects, the next NEW client
becomes 1, not 0 again.

1) COMPILE — any terminal
   gcc -Wall -Wextra -Werror practice.c -o server

2) START SERVER — Terminal 1
   ./server 8081
   (leave running, don't type here again until Test 5)

3) CLIENT A — Terminal 2
   nc localhost 8081

4) CLIENT B — Terminal 3
   nc localhost 8081
   → Terminal 2 shows: server: client 1 just arrived

---------------------------------------------
TEST 1 — basic message
   Terminal 2: type  hello  + Enter
   → Terminal 3: client 0: hello
   → Terminal 2: nothing (you don't see your own message)

TEST 2 — multi-line paste
   Terminal 2: paste this whole block at once (ends with Enter):
     line1
     line2
   → Terminal 3 shows two separate lines:
     client 0: line1
     client 0: line2

TEST 3 — partial line
   Terminal 2: type  hel   (no Enter)
   → Terminal 3: nothing yet
   Terminal 2: type  lo  + Enter
   → Terminal 3: client 0: hello

TEST 4 — disconnect
   Terminal 2: press Ctrl+C
   → Terminal 3: server: client 0 just left

TEST 5 — no argument
   Terminal 1: stop server (Ctrl+C), then run:
   ./server
   → prints: Wrong number of arguments
   → exits with status 1

TEST 6 — 3+ clients
   Open Terminal 4: nc localhost 8081
   Type a message in any one client → every OTHER client receives it,
   the sender does not.
