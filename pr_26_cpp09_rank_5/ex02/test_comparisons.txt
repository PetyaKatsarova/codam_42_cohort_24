## How to Test

1. Compile: `make` or `c++ -Wall -Wextra -Werror -std=c++98 *.cpp -o PmergeMe`
2. Run test: `./PmergeMe 3 2 1`
3. Check output shows "Total comparisons: X (n=3)"
4. Compare X with the table above

## Understanding the Output

- **Binary search comparisons**: Only counts binary search operations during insertion
- **Total comparisons**: ALL comparisons including:
  - Pair creation comparisons (n/2)
  - Sorting pairs comparisons (~O(n/2 log n/2))
  - Binary search insertion comparisons
  
The total should match (or be very close to) the optimal values in the table for small inputs.

## Note on Accuracy

For small n (< 12), your implementation should match exactly.
For larger n, you might be slightly higher due to std::sort implementation details,
but you should still be significantly better than standard sorting algorithms like 
quicksort (O(n log n) comparisons on average).
